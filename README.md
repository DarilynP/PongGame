# 🏓 Pong Game

A simple two-player **Pong clone** built with **Python** and **Pygame** — inspired by the classic 1972 Atari arcade game.  
 
---

## 🎮 Gameplay

Two players battle it out in a retro-style Pong match:

- **Player 1 Controls:** `W` (Up) and `S` (Down)  
- **Player 2 Controls:** `↑` (Up Arrow) and `↓` (Down Arrow)  
- **Start Game:** Press `Spacebar`  
- The ball bounces off walls and paddles — if it passes a paddle, the round ends.  

---

## 🧠 What I Learned

- Drawing and animating shapes using **Pygame**  
- Understanding **game loops**, **frame rates**, and **delta time**  
- Handling keyboard input (`KEYDOWN` and `KEYUP` events)  
- Detecting collisions with `pygame.Rect()`  
- Managing game state and smooth movement
